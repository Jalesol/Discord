# 💬 Discord Landing Page - Clone

Projeto desenvolvido com o objetivo de recriar a clássica landing page do Discord, focando em fidelidade visual, estruturação de layout moderno e interatividade.

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias:
- **HTML5** (Estruturação semântica)
- **CSS3** (Estilização avançada, flexbox, responsividade)
- **JavaScript** (Interatividade e dinamismo na interface)
- **Git & GitHub** (Controle de versão)

## 📌 Sobre o Projeto

O intuito foi replicar a identidade visual marcante da plataforma, prestando atenção em detalhes como:
- Tipografia e paleta de cores característica.
- Seções de apresentação (como o "Imagine um lugar...", canais de voz e organização de comunidades).
- Layout responsivo adaptado para diferentes tamanhos de tela.
